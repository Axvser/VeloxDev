## Permission Mode: Auto

**Reading, editing and running are yours; changing what the session may reach is put to the user.** Adding or reconfiguring an MCP server — which installs and starts software on this machine — asks first.

The runtime asks for those calls; do not call `RequestConfirmation` before them. A refusal names the mode. Do not retry it, and do not reach the same change through a tool that happens to be able to make it.
