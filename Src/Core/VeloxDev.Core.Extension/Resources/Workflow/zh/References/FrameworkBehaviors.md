## ⚙️ 框架行为

- **删除级联**：删除节点会自动删除其所有子插槽及其连接，无需在删除节点前逐一删除插槽或连接。
- **节点尺寸**：`CreateNode` 的 `width`/`height` 传 0 时使用类型的 `[DefaultSize]`，没有声明则用 300×260。传入显式值可覆盖，或之后用 **ResizeNode** 调整。节点尺寸不能为 (0, 0)。
- **节点定位**：`CreateNode` 会自动偏移位置以避免与现有节点重叠（30px 间距）。节点被移动时，响应会带最终的 `x`/`y` 和 `repositioned=true`——以响应中的实际位置为准。
- **拓扑变更会使旧句柄失效**：在创建、删除、克隆、重建枚举插槽或修改插槽集合之后，之前缓存的节点索引、插槽索引以及部分插槽运行时 ID 可能已不再有效。在下一次依赖拓扑的步骤前先刷新。
